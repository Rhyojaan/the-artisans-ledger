# Project Codename

Project Codename is an Elder Scrolls Online companion application currently focused on Alchemy, with future support planned for every crafting profession, collections, and account progression.

## Current Module

### The Alchemist

Features include:

- Trait discovery
- Inventory tracking
- Intelligent experiment planner
- Recipe builder
- Favorites
- Character archives
- Aldren guidance

## Philosophy

Players should spend more time playing ESO and less time searching multiple websites.

Aldren serves as the player's guide by analyzing information from every system and providing meaningful recommendations.
