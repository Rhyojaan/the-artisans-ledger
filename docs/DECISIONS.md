# Project Decisions

## 2026-06-30

### Decision
Aldren is the intelligence layer of Project Codename.

**Reason**
Every profession and collection provides information to Aldren. Aldren presents meaningful advice to the player.

---

### Decision
The Alchemist is a module, not the final application.

**Reason**
The application will eventually contain multiple professions. "Project Codename" remains the umbrella name until the final name is chosen.

---

### Decision
Profession tabs are added only when they are complete.

**Reason**
Players should never see unfinished or "Coming Soon" features.

---

### Decision
Every commit must leave the application in a working state.

**Reason**
The application should always be recoverable and testable.

---

### Decision
Players should enter information only once whenever possible.

**Reason**
Aldren should reuse existing information instead of asking the player repeatedly.

---

### Decision
Profession levels determine material recommendations.

**Reason**
Aldren should automatically know the correct solvent, ore, cloth, wood, and other material tiers based on the player's profession level.

---

### Decision
If a feature reduces the need to visit another ESO website, it belongs in Project Codename.

**Reason**
The long-term goal is to create the player's primary ESO companion.

---

### Decision
Player-facing features are released only when they provide complete value.

**Reason**
Half-finished features and empty tabs create clutter and reduce the quality of the user experience.
